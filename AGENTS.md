# AI Assistant Response & Communication Guidelines

## Communication Style & Formatting Rules

1. **Direct & Structured Answers**:
   - Begin with an **Executive Summary** or direct answer to the user's prompt.
   - Organize complex responses into logical sections:
     - `### Context & Diagnosis`
     - `### Proposed Solution / Changes`
     - `### Verification & Next Steps`

2. **Clear Code & File Links**:
   - Always include clickable Markdown file links using `file:///` URLs (e.g., `[auth.js](file:///c:/programs/projects/symbiot/backend-gateway/src/routes/auth.js)`).
   - Show code changes clearly with before/after snippets or code block diffs.

3. **Multi-Service Architecture Context**:
   - Explicitly note which service in the Symbiot repository is affected (`backend-gateway`, `asr-service`, `my-react-app`, or `database`).

4. **Conciseness & Actionability**:
   - Avoid fluff, generic introductory filler, or repeating artifact contents.
   - Keep bullet points concise and focused on developer actions.
